# ВЕНАРУС — лендинг препарата

Учебный pet-проект: вёрстка лендинга фармацевтического препарата по готовому дизайн-макету (изначально выполнялось как тестовое задание). Реализовано на чистом HTML/CSS/JS с использованием Bootstrap для каруселей.

🔗 Демо: [artyom-tyshchenko.github.io/venarus](https://artyom-tyshchenko.github.io/venarus/)

## Стек

- HTML5
- SASS/SCSS → компилируется в `style.css`
- Vanilla JavaScript (без фреймворков)
- [Bootstrap 5](https://getbootstrap.com/) — карусели и утилиты
- Адаптивное масштабирование макета через JS (scale wrapper)

## Возможности

- Адаптивная вёрстка — макет корректно масштабируется под ширину экрана, включая шапку с бургер-меню
- Бургер-меню с якорной навигацией по разделам сайта
- Модальные окна: схема приёма препарата, инструкция, карта аптек (Google Maps)
- Переключение изображений дозировок стрелочками в шапке
- Разделы: о препарате, о варикозе, схема приёма и рекомендации, информация для специалистов, о геморрое
- Видео-контент: мнения врачей, видео о производстве
- Интерактивные карточки с hover-эффектами и ссылками на статьи
- Ссылки на партнёрские аптеки (apteka.ru, 366.ru, stolichki.ru) с анимацией при наведении

## Быстрый старт

Проект не требует сборки — достаточно открыть `index.html` в браузере или поднять локальный сервер:

```bash
git clone https://github.com/Artyom-Tyshchenko/venarus.git
cd venarus
npx serve .
```

Если вносите изменения в стили — редактируйте `src/sass/style.sass` и компилируйте в `style.css` любым SASS-компилятором (например, расширением Live Sass Compiler в VS Code).
